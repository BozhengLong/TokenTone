# Audio Samples

This directory contains audio samples for TokenTone themes.

## Directory Structure

```
samples/
├── lofi/           # Lo-fi hip hop samples
│   ├── rhodes-c4.wav
│   ├── rhodes-e4.wav
│   └── ...
├── ambient/        # Ambient/atmospheric samples
│   ├── pad-c3.wav
│   ├── chime-high.wav
│   └── ...
└── synthwave/      # 80s synthwave samples
    ├── synth-stab-c4.wav
    ├── bass-hit.wav
    └── ...
```

## Sample Requirements

- Format: WAV (preferred), MP3, OGG, or AIFF
- Duration: 50-200ms for note samples
- Sample rate: 44.1kHz or 48kHz
- Bit depth: 16-bit or 24-bit

## Licensing

All samples should be CC0 (public domain) or have appropriate licensing for distribution.

Recommended sources:
- Freesound.org (filter by CC0 license)
- Archive.org
- Custom recordings
